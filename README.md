# Чат-бот школы английского — инструкция по деплою

## Структура проекта
```
english-school-bot/
├── index.html       ← сайт с чат-виджетом (то, что видит пользователь)
├── api/chat.js       ← серверная функция, которая безопасно хранит API-ключ
├── package.json
└── README.md
```

## Шаги

### 1. Получите API-ключ Anthropic
- Зайдите на console.anthropic.com
- Создайте API-ключ (раздел API Keys)
- Скопируйте его — он вам понадобится на шаге 4

### 2. Загрузите проект в GitHub
- Создайте новый репозиторий, например `english-school-bot`
- Загрузите туда все файлы из этой папки, сохранив структуру
  (важно: файл `chat.js` должен лежать именно в папке `api/`)

### 3. Подключите репозиторий к Vercel
- На vercel.com → **Add New → Project**
- Выберите ваш репозиторий → **Import**
- На экране настроек НЕ нажимайте Deploy сразу — сначала перейдите к шагу 4

### 4. Добавьте переменную окружения
- В настройках проекта на Vercel найдите **Environment Variables**
- Добавьте:
  - **Key**: `ANTHROPIC_API_KEY`
  - **Value**: ваш ключ с шага 1
- Сохраните

### 5. Задеплойте
- Нажмите **Deploy**
- Через минуту получите ссылку вида `english-school-bot.vercel.app`
- Откройте — бот должен отвечать

## Как редактировать базу знаний бота
Откройте `api/chat.js`, найдите переменную `SYSTEM_PROMPT` в начале файла —
там текстом описано всё, что бот знает про курсы, цены, уровни.
Отредактируйте текст, сохраните файл, залейте изменения в GitHub —
Vercel передеплоит сайт автоматически.

## Дальше — Telegram и WhatsApp
Функция `api/chat.js` уже содержит всю логику бота. Чтобы подключить
Telegram, потребуется отдельная функция-обработчик, которая получает
сообщения от Telegram (через вебхук от @BotFather) и вызывает ту же
логику. Спросите об этом в чате с Claude, когда будете готовы к этому шагу.
